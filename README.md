# Sumara Labs Web v2

Next-generation corporate website and digital product showcase for **Sumara Labs**, inspired by premier agency design references such as [Shakuro](https://shakuro.com/).

## 🚀 Key Features & Shakuro-Inspired Architecture

- **High-Impact Visual Agency Aesthetic**: Deep onyx background (`#09090b`), high-contrast typography (`Plus Jakarta Sans`, `Space Grotesk`, `JetBrains Mono`), radial ambient glows, and clean glassmorphism.
- **Smooth Kinetics**: Integrated [Lenis](https://github.com/darkroomengineering/lenis) smooth scrolling and Framer Motion micro-interactions.
- **Interactive Project Modal**: Rich case study drawer/modal detailing challenges, architectural solutions, delivered milestones, and business impact metrics.
- **Filterable Showcase Gallery**: Dynamic category filtering (Healthcare Tech, FinTech & Web3, Enterprise SaaS, Mobile Apps) with impact metric overlays.
- **Modular Discipline Grid**: Expandable multi-disciplinary capability cards with deliverable checklists and technical stacks.
- **Interactive Cost & Scope Estimator**: A dynamic proposal tool allowing prospective partners to configure project scope, stages, core capabilities, and timelines.
- **Transparent Commercial Packages**: Transparent pricing tiers (Startup Launchpad, Company Profile & Product Showcase, Enterprise Web App & SaaS).
- **Global Presence**: Hub showcases in Prague (Czech Republic) and Jakarta (Indonesia).

## 🛠 Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom Design Tokens
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Scroll Engine**: Lenis Smooth Scroll
- **Routing**: React Router v6

## 📦 Getting Started

```bash
# Navigate to sumara-web-v2
cd sumara-web-v2

# Start the development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
